# Project Brief

## Goal
Build a data scraper for fantasy football that powers analysis in a Jupyter
notebook.

## Core Requirements
- A Python CLI (Typer) that fetches data and stores it as CSV/JSON.
- A Jupyter notebook that imports the same code and analyzes the data.
- Reproducible, resumable scraping with polite rate limiting.
